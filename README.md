# DA-Project
This report is a descriptive analysis of 20,000 Flipkart product listings (Dec 2015 to Jun 2016). The catalog's total value is about Rs. 5.94 crore, with an average price of ~Rs. 2,979 and a median of Rs. 1,040. Clothing has the most listings (~31%), but Jewellery leads in value (~45.5%).
